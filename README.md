# Triumph Task Manager

A modern, responsive task management application built with HTML, CSS, and vanilla JavaScript.

Triumph Task Manager helps users organize their daily tasks, track their progress, and stay productive with a clean and intuitive interface.

## ✨ Features

- Add new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Mark tasks as completed or active
- Search tasks
- Filter tasks by:
  - All
  - Active
  - Completed
- Task statistics
  - Total tasks
  - Completed tasks
  - Pending tasks
- Task creation date and time
- LocalStorage persistence
- Dark and light mode
- Saved theme preference
- Empty states
- Responsive design
- Keyboard support
- Accessible buttons and controls
- Modal-based editing and deletion
- Duplicate-task prevention

## 📱 Responsive Design

The application is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices
- Small-screen devices

CSS media queries are used to adapt the layout for different screen sizes.

## 💾 Data Persistence

Tasks are stored in the browser using the JavaScript `localStorage` API.

This means tasks remain available even after refreshing or closing the browser.
